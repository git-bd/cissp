## ✅Single/Multifactor Authentication
* **MFA** : Multi Factor Authentication il se base sur 4 types : 
> 1. Type 1 : quelque chose que l'on connait  `Know`
> 2. Type 2 : quelque chose que l'on a `Have`
> 3. Type 3 : quelque chose que l'on est ou fait `Are`

Common Access Control Errors : 
* **FRR** : Type II, False Rejection Rate (false negative)
* **FAR** : Type II, False Acceptance Rate (false positive)
* **CER** : Crossover Error Rate
